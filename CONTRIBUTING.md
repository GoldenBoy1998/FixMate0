# Contributing to FixMate

FixMate welcomes focused contributions that preserve the Arabic RTL experience, independent marketplace positioning, privacy, and the portable workspace architecture.

Before opening a pull request, run `pnpm install`, `pnpm run typecheck`, and the relevant build or database checks. Do not commit `.env`, credentials, production data, or unlicensed assets. Describe schema changes, API changes, migration requirements, and any remaining deployment assumptions.

Feature work should include validation and tests where the repository supports them. Security issues should not be disclosed in a public issue; use the private reporting path documented by the repository owner.
